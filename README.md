# Mani Match

A luxury, single-page nail atelier. A six-question consultation (name, undertone, hands, style, service, brands) sets up a personal **Monthly Edition**: one signature shade unveiled on the first of each month, plus a quiet and a statement alternative, each with the salon code (or exact shade name), shape, length and Gel-X tip. Clients mark what they wore and how it wore; their **Collection** builds a year in colour and future editions learn from it. A full **Library** (556 shades, 22 brands) and a salon **Guide** sit alongside.

Everything is saved on the client's own device (localStorage); there is no backend.

Open `index.html` in a browser. No build step or dependencies.
