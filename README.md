# Mani Match

A single-page web app that helps you choose a nail color, shape and length for the season, the occasion and your mood. It gives you the salon code (or exact shade name) to show your nail tech, plus the Gel-X tip to ask for if you want extensions. The library covers 556 shades from 22 brands.

Open `index.html` in a browser. No build step or dependencies.
